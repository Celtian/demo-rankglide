# Rankglide Demo

A responsive single-page demo of a [Rankglide](https://rankglide.io/) visualization, built with Vite, TypeScript, and Tailwind CSS.

## 🛠️ Installation

The project requires Node 24 and Bun 1.4.2 or newer.

```sh
bun install
```

Consider installing the recommended VS Code extensions from `.vscode/extensions.json` before starting.

## 🚀 Development server

```sh
bun run dev
```

Open `http://localhost:5173`.

## 📦 Build

```sh
bun run build
```

## 🧹 Lint

```sh
bun run lint
```

## 🚀 Deploy

Deployment to GitHub Pages is handled by the GitHub Actions workflow when changes are pushed to `master`.
